# Yggdrasil Documentation

Thư mục này chứa toàn bộ các tài liệu thiết kế hệ thống, quy chuẩn kỹ thuật và các quyết định kiến trúc quan trọng (ADRs) của nền tảng Yggdrasil v0.1.

## Cấu trúc thư mục

- /architecture: Chứa các bản thiết kế High-level (Data Flow, Orchestration Flow, v.v.) được đúc kết từ Obsidian.
- /adrs (Architecture Decision Records): Chứa lịch sử các quyết định kỹ thuật cốt lõi (Ví dụ: Tại sao chọn Iceberg? Tại sao dùng DuckDB thay cho Spark?). Mỗi quyết định là một mốc lịch sử không thể đảo ngược mà không có lý do.
